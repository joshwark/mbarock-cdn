How to use this console
  • Site health updates automatically every 60s. Green = good, gold = warning, red = action needed.
  • Quick actions create a request row + email Josh. They aren't fixes themselves — they queue up the work.
  • Request queue shows everything submitted. Click any row to see full context, add notes, or change status.
  • Realtime means Supabase pushes changes live — when Josh updates a task, you see it without refresh.
  • Critical issues surface in the orange/red banner at the top.
  • If something is broken or confusing, use "Send to Josh" with a clear note — that's the safety net.
